## Travelport test API

This project now exposes:

- `POST /travelport/search`
- `POST /flights/search` (same provider pipeline)

### Fast search behavior

Both search endpoints are optimized with:

- deterministic request-key cache (`FLIGHTS_SEARCH_CACHE_ENABLED`)
- short TTL results cache (`FLIGHTS_SEARCH_CACHE_TTL_SECONDS`, default `90`)
- in-flight request deduplication for identical concurrent searches
- per-IP rate limiting on search routes (`RATE_LIMIT_TTL_MS`, `RATE_LIMIT_LIMIT`)

Set these environment variables before running:

- `TRAVELPORT_USERNAME`
- `TRAVELPORT_PASSWORD`
- `TRAVELPORT_CLIENT_ID`
- `TRAVELPORT_CLIENT_SECRET`
- `TRAVELPORT_ACCESS_GROUP` or `TRAVELPORT_PCC` (at least one)
- Optional: `TRAVELPORT_GDS` (default `1G`)
- Optional: `TRAVELPORT_AUTH_URL` (default `https://auth.pp.travelport.net/oauth/token`)
- Optional: `TRAVELPORT_BASE_URL` (default `https://api.pp.travelport.net`)
- Optional: `TRAVELPORT_ACCEPT_VERSION` (default `11`)
- Optional: `TRAVELPORT_CONTENT_VERSION` (default `11`)
- Optional: `TRAVELPORT_REQUEST_TIMEOUT_MS` (default `20000`)
- Optional: `TRAVELPORT_DEFAULT_CONTENT_SOURCE_LIST` (default `GDS`, comma-separated)
- Optional: `TRAVELPORT_OAUTH_GRANT_TYPE` (default `password`)
- Optional: `TRAVELPORT_OAUTH_CLIENT_AUTH_MODE` (`basic` or `body`, default `basic`)
- Optional: `TRAVELPORT_INCLUDE_ACCESS_GROUP_IN_TOKEN` (default `false`)

You can bootstrap quickly with:

```bash
cp .env.example .env
```

On Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Example request:

```bash
curl -X POST http://localhost:3000/travelport/search \
  -H "Content-Type: application/json" \
  -d '{
    "from": "KHI",
    "to": "DXB",
    "departureDate": "2026-07-10",
    "adults": 1
  }'
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
